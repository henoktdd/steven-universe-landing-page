# Steven Universe Landing Page

A custom landing page inspired by Cartoon Network's *Steven Universe*, created as part of [The Odin Project](https://www.theodinproject.com/) Web Development Foundations curriculum.

**Live Demo:** https://henoktdd.github.io/steven-universe-landing-page/

## Overview

This project builds a complete landing page from scratch using HTML5 and CSS Flexbox. The design showcases key characters from the series (Steven, Garnet, Amethyst, and Pearl), themed color palettes, and a call-to-action section.

## Features

- **Header & Navigation:** Styled header with a custom logo and navigation links.
- **Hero Section:** Intro section featuring high-contrast typography, hero graphics, and a call-to-action button.
- **Character Showcase:** Interactive grid of profile cards with rounded borders displaying the Crystal Gems.
- **Quote Section:** Styled blockquote with custom typography and attribution.
- **CTA Section:** Call-to-action box encouraging users to join the team.
- **Footer:** Clean footer with copyright information.

## Built With

- **HTML5** — Semantic structure and content markup
- **CSS3** — Flexbox layout model, visual styling, and custom color scheme
- **Fonts** — Roboto
